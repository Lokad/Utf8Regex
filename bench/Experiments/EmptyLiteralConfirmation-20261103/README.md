# Skip confirmation only when no requirement exists

An accepted literal candidate with no boundary or nonempty trailing requirement
previously charged an empty confirmation immediately before charged terminal
publication. The finder now skips only that empty confirmation. Actual candidate
search/comparison blocks, all real requirements, sticky failures, empty plans,
and terminal success/miss checks retain original work/cancellation/deadline
authority. Numerical work minima intentionally decrease; admission/lifetimes and
strict whole-subject UTF-8 validation are unchanged. No new flag, mode or owner.

under 120s, minimum sample **45.572ms**. Original `a40bda03`, parent `a3f995fe`
and its Core patch; Python DLL/PDB are byte-identical across parent/candidate.
