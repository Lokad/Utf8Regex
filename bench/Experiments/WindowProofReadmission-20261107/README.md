Promote the existing per-window proof on current source. A backwards class step
already proves membership at its new start. If it makes no progress, classify
only the unproved conservative prefix, stopping at its first actual member.
Every viable start retains complete VM verification. Fully rejected Count

existing handling. No field, helper, plan, threshold, mode or framework is added.

NonBacktracking remain. Classification spends bounded work under the original
token/deadline. Required VM capacity remains admitted before acquisition; skipped
attempts can lower numerical work, depth and working/heap requirements. The

[PCRE2](../../../docs/SPEC-PCRE2.md) contracts record this resource change.
