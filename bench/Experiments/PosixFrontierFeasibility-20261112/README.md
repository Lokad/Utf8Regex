This extends the [conservative dominance model](../PosixDominanceModel-20261112/README.md) with two scalar-position state banks, per-PC linear buckets and independent history records. Joins retain exact counters/progress/openings; unresolved histories remain incomparable. Stale queued records remain accounted. It is a private functional experiment, not another shipped executor.
