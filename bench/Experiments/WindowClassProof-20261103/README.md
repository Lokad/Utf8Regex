# Once-per-window class proof: rejected and restored

The trial classified only an unproved conservative window prefix inside the
existing scalar rewind helper. A successful backwards class rewind already proves
its first scalar is a member; the trial reused that fact, without a new predicate
on every VM attempt. Fully rejected windows advanced to the next delimiter before
VM workspace admission. Actual scalar predicates, complete verification of all
remaining starts, metering and original interruption authority were preserved.
No new helper, field, plan, threshold, backend or mode was added.

This distinct proof/frequency design was scoped before editing. The earlier
[per-attempt trial](../ClassStartFilter-20261103/README.md) remains closed. Both
trials retain the same twenty public workloads, driver and measurement settings.

five alternating batches, complete Count results consumed after timing and actual
allocations remain. Compatible predecoded/decode-then .NET diagnostics are separate.
No original-corpus or cumulative delivery gate was replayed.
