`2a3c77cd`. One flat two-way fork has capture-wrapped, literal-only branches with
the same positive scalar length and no consuming suffix. A successful branch
therefore ends at the same input boundary. If both succeed, the earlier branch's
whole-span tag precedes the later branch's tag; participation beats absence before
descendant captures can break the tie. Trusted lowering supplies balanced tags.
Empty/unequal branches, loops, nested forks, assertions and consuming tails retain
general POSIX competition. No new executor, field, buffer or mode is introduced.
The cold instruction scan retains bounded construction work charges.
