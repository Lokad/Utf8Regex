qualified baseline producersfaa48f57). Core/Python/Pcre2 bytes and all484 existing
package/symbol assets remain unchanged. No package or Full refresh for this trial.

fixes the earliest longest whole match. Immutable finite byte bounds exclude
impossible splits. One memo and an admitted explicit dependency/projection buffer
replace general best-trace copying, scoped comparison and prefix/parent/root

iteration/empty/absence order, original interruption, aliases and retained values
remain. **Accounting changes:** dependency/projection depth differs from pending
DFS alternatives; work counts change. Dictionary capacity is conservatively
charged as4 typed key/value-plus-index-array extents before growth, including
old/new overlap. Working/result scopes remain modeled capacity, not total heap/RSS.
All loans refund synchronously. The [contract](../../../docs/SPEC-POSIX.md#interruption-and-admission)
replaces the removed implementation details and records these trade-offs.
