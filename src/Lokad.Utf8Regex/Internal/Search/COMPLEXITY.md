# Prepared search and retained execution-kernel complexity

This file is the complexity contract for the flavor-neutral prepared search
kernels and the retained direct execution kernel listed below. Here, `n` is
the searched byte length, `m` is one literal length, `L` is the sum of prepared
literal lengths, `k` is the number of literals, `c` is the number of candidates
returned to a verifier, and `w` is a fixed match width. Preparation is paid
once per compiled regex; scan state is retained by operation cursors.

| Owner | Preparation | Stateful scan envelope | Retention rule |
|---|---:|---:|---|
| `PreparedByteSearch` | `O(k + alphabet)` | `O(n)` | One admitted byte copy and, for sets larger than three bytes, an owned immutable byte set. Shared empties acquire nothing. |
| `PreparedSubstringSearch` | `O(m + alphabet)` | `O(n * m)` worst case; vector/Boyer-Moore tiers are sublinear on favorable input | Shift tables and selected comparison offsets are prepared once. |
| `PreparedQuotedAsciiRunSearch` | `O(1)` | `O(n)` | No candidate revisits an earlier opening quote. |
| `PreparedAsciiIgnoreCaseLiteralSetSearch` | `O(L + alphabet)` | `O(n * max(m))` worst case | Admitted immutable descriptor, folded payloads, ordered buckets/maps and owned first-byte search use fixed alphabet scratch. Empty families borrow state; empty alternatives preflight before normalization. Eligible masks release their temporary grouped reference vector after copying; ineligible masks borrow original lengths without flattening. Long literals select three correlated offsets; shorter literals retain up to four leading offsets. Scalar and correlated scans advance monotonically. |
| `PreparedSmallAsciiLiteralFamilySearch` | `O(L + alphabet)` | `O(n * k * max(m))` worst case | Admitted eligibility/exact data, owned anchor search, selected filter values and pair entries use fixed four-entry ranking and alphabet stamps. One-bucket families decline before acquiring data; only selected metadata is allocated, without unused prefix copies or second-byte membership. Triple dispatch borrows three literals. Discriminators select a literal for full verification; they do not prove an unchecked prefix. Rejected candidates advance by at least one byte. |
| `PreparedLiteralSetSearch` | `O(L * alphabet)` worst case | `O(n * k * max(m))` worst case | Admitted exact ordered buckets, prefix copies, membership filters and discriminator/first-byte maps use fixed alphabet scratch and owned byte search. Only the selected unique anchor or trie is prepared. The unused second-byte search tier is removed; its live membership filter remains. Borrowed-data trie preparation releases its temporary reference vector after key/order/length copying. |
| `PreparedMultiLiteralSearch` wrapper and earliest tier | `O(L + k * alphabet)` selection, plus the selected kernel | Earliest: `O(n * k * max(m))` worst case | Admitted selection/depth and borrowed-search reference vectors preserve grouped branch order. Raw construction builds only the selected kernel, without discarded exact metadata or duplicate anchor/trie preparation. Earliest borrows the vector and scans lengths once. Automaton trie verification and earliest/hybrid Count helpers have live consumers. |
| `PreparedShortAsciiLiteralFamilyCounter` | `O(m² * k² + alphabet)` with `k <= 4`, `3 <= m <= 8` | `O(n * k * m)` worst case | Eligibility and pair scores use admitted work and fixed four-byte scratch. Only distinct selected membership bytes and their owned search are acquired; literals are borrowed. Candidate arrays, duplicate membership bytes, opaque SearchValues and the unused longest-length calculation are removed. |
| `PreparedBmpThreeByteLiteralFamilySearch` | `O(k * g)` with `g <= k` distinct guards per offset | `O(n * k * max(m))` worst case | Active admitted value buffers freeze to ordered vectors and distinct three-byte copies. Inactive guards borrow empties; too-short families decline before acquisition. The caller proves BMP shape and the runtime validates UTF-8/full literals. Duplicate guard families use constant metadata storage. |
| Literal runtime factory preparation | `O(L + k²)` eligibility and ordering, plus active prepared kernels | Uses the selected kernel's bound | Root, composite holder and selected literal wrapper field state/retainers are admitted. Small families use fixed eight-entry ordering scratch and owned byte search, borrowing an already ordered vector. Leading/BMP shape probes, primitive minimum length and composite concatenation share work/depth admission. Only the selected runtime is constructed; no discarded literal/nonliteral runtime, unused enumeration field or raw candidate vector remains. Other runtime roots, fallback scans and dynamic emission remain uncovered. |
| `PreparedMultiLiteralSearch` packed/mask-prefilter tiers | `O(L + k * alphabet)` | `O(n * k * max(m))` worst case | Mask and discriminator preparation admits required final tables and shared byte-search state. Offset ranking retains three stack scores; folded ranking uses at most eight weights and three selected offsets. Absent discriminator anchors borrow empty tables. Packed reverse search excludes a rejected start; AVX2, SSE, and scalar candidate methods are unchanged. |
| `PreparedMultiLiteralLeadingUtf8SegmentPrefilter` | `O(k * g * s + k)` with `g <= k`, `s <= 6` | `O(n * g * s)` worst case | Admitted distinct-segment storage preserves first-encounter order; no per-bucket literal references or assignment/count state survive. Identical-prefix families use constant storage. Candidate search uses the same ordered segment bytes. |
| `PreparedMultiLiteralSearch` automaton tier | `O(L * alphabet)` | `O(n + matches)` | Admitted value-state and dense transition buffers complete failures through an exact temporary queue. The final matrix transfers or admits a final copy; no per-node arrays or mutable objects survive. Scan state is carried in `PreparedMultiLiteralScanState`; it never restarts after a rejected match. |
| `PreparedMultiLiteralSearch` trie tier | `O(L * alphabet)` | `O(n * max(m))` worst case | Admitted node/edge value buffers freeze to immutable node/key/child arrays and the root map. Sibling chains contain at most 256 entries; sorting uses one fixed stack row. Temporary arrays release before return; empty tries borrow all state. |
| `Utf8InvariantCyrillicLiteralCountStrategy` | `O(L + k * alphabet)` | `O(n * k * max(m))` worst case | At most eight plain-literal branches share the packed candidate scan when SIMD is available; every correlated, shared-anchor, and per-branch fallback cursor advances monotonically. |
| `PreparedSearcher` | selected-owner cost | selected-owner cost | It is a typed dispatcher and does not add another scan; overlapping byte-set cursors advance at least one byte after every candidate. |
| `PreparedWindowSearch` | two selected-owner costs | `O(leading work + trailing work + c)` | Leading and trailing scan states are both retained. A dense leading stream with an absent trailing literal scans the trailing suffix once, not once per leading candidate. |
| `Utf8LiteralEquality` | `O(1)` | `O(m)` per requested comparison | Bounds checks precede every comparison; no input scan is hidden here. |
| `AsciiSearch` preparation helpers | `O(L + k * alphabet)` | none | These helpers only construct retained search data. |
| `Utf8SearchKernel` scalar/vector primitives | `O(1)` | `O(n)` | Each primitive is a single monotone pass over its supplied span. |
| `Utf8AsciiDeterministicFixedWidthCountExecutor` | `O(1)` selection over retained fixed-width checks | `O(n * w)`, therefore `O(n)` for admitted `3 <= w <= 8` | The AVX2 dense-input tier keeps non-overlapping progress in `nextStart`; after four empty literal blocks it transfers once to a monotone scalar suffix instead of restarting the input. |

Compositions may multiply candidate confirmation by the confirmed literal
length, but no prepared kernel restarts a losing source at byte zero. Candidate
portfolio merging is accounted for separately by `Utf8CandidatePortfolioCursor`:
each source advances monotonically and total merge work is linear in the sum
of source advances plus yielded candidates.

Any new retained kernel must add a row here and an adversarial test or warm
benchmark covering its declared worst-case input shape.
